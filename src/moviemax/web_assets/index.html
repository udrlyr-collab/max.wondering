Telegram 연결

@BotFather에서 봇을 만든 뒤 발급된 Bot API token을 입력하세요.

  1. 1

    BotFather에서 /newbot을 실행합니다.

  2. 2

    생성된 봇 대화에서 /start를 보냅니다.

  3. 3

    토큰 입력 후 채팅을 선택하고 저장합니다.

공유되거나 노출된 토큰은 사용하지 마세요. BotFather에서 /revoke한 뒤 새 토큰을 발급하세요.

토큰은 서버의 별도 키로 암호화되며 화면에 다시 표시되지 않습니다.
