감시 대상 추가

극장과 영화, 추적할 상영 포맷을 차례로 선택하세요.

현재 CGV 시간표에서 확인되는 영화와 상영 포맷을 표시합니다.

Telegram 연결

@BotFather에서 봇을 만든 뒤 발급된 Bot API token을 입력하세요.

  1. 1

    BotFather에서 /newbot을 실행합니다.

  2. 2

    생성된 봇 대화에서 /start를 보냅니다.

  3. 3

    토큰 입력 후 채팅을 선택하고 저장합니다.

공유되거나 노출된 토큰은 사용하지 마세요. BotFather에서 /revoke한 뒤 새 토큰을 발급하세요.

토큰은 서버의 별도 키로 암호화되며 화면에 다시 표시되지 않습니다.

브라우저 알림

이 기기에 잔여석 증가 알림을 보냅니다. 사이트가 닫혀 있어도 서버에서 직접 발송합니다.

지원 상태를 확인하는 중입니다.

알림 권한은 켜기 버튼을 누를 때만 요청합니다.

iPhone·iPad는 이 사이트를 홈 화면에 추가한 뒤, 홈 화면의 웹 앱에서 설정하세요. 구독 주소와 암호화 키는 서버에서 암호화해 보관합니다.

감시 대상 삭제

이 작업은 되돌릴 수 없습니다.

선택한 감시 대상

감지를 즉시 중단하고 이 대상의 모든 상영 회차, 좌석 변동 이력, 알림 기록과 대기 중인 브라우저 알림을 함께 삭제합니다.
